    Uncertainty

    Uncertainty is the lack of the exact knowledge that would let us reach a perfectly reliable conclusion. Expert systems meet it from four sources:

    Weak implications

    The link between a condition (IF) and an action (THEN) is not certain.

    Imprecise language

    Words such as often, sometimes or hardly ever mean different things to different people.

    Unknown data

    Data is missing or incomplete, so the system must reason with approximate values.

    Combining experts

    Different experts give different, sometimes conflicting, views.

    Fuzzy logic handles the imprecise language problem: it lets the system use vague words in a precise, mathematical way.

    Crisp sets vs fuzzy sets: "tall men"

    In a crisp (Boolean) set, a man is either tall (1) or not (0), with a sharp line at 180 cm. In a fuzzy set, every man belongs to "tall" to some degree of membership between 0 and 1.

    Linguistic variables and hedges

    A linguistic variable takes words as values: height can be short, average or tall. Hedges such as very, somewhat and extremely modify a fuzzy set mathematically.

    Try it: apply hedges to "tall"

    HedgeFormulaMembership

    Concentration hedges (very, extremely) make the set stricter, so values drop; dilation hedges (somewhat, more or less) make it looser, so values rise.

    Exercise 3.1

    Tom's membership in "tall" is 0.82. Calculate his membership in very tall and in somewhat tall (2 decimal places).

    Show working

    Very: 0.82² = 0.6724 ≈ 0.67. Somewhat: √0.82 = 0.9055 ≈ 0.91.

    Fuzzy rules and fuzzy operators

    A fuzzy rule has the form IF x is A THEN y is B, where A and B are linguistic values (fuzzy sets).

    A classical rule fires completely or not at all. A fuzzy rule fires to a degree: if the antecedent is partly true, the consequent is partly true by the same degree.

    OperatorFuzzy versionExample (0.2 and 0.7)
    ANDmin(μA, μB)0.2
    ORmax(μA, μB)0.7
    NOT1 − μANOT 0.2 = 0.8
    Exercise 4.1

    Rule: IF project funding is marginal AND project staffing is large THEN risk is normal. The memberships are μ(marginal) = 0.2 and μ(large) = 0.7. What is the firing strength of the rule?

    Show working

    AND uses the minimum: min(0.2, 0.7) = 0.2.

    Mamdani inference: the lecture example step by step

    The lecture's two-input example estimates project risk (z) from project funding (x) and project staffing (y):

    RuleStatement
    1IF funding is adequate (A3) OR staffing is small (B1) THEN risk is low (C1)
    2IF funding is marginal (A2) AND staffing is large (B2) THEN risk is normal (C2)
    3IF funding is inadequate (A1) THEN risk is high (C3)
    Step 1: Fuzzification

    The crisp inputs give: μ(A1) = 0.5, μ(A2) = 0.2, μ(A3) = 0.0; μ(B1) = 0.1, μ(B2) = 0.7. These are given; move on to step 2.

    Step 2: Rule evaluation

    Calculate the firing strength of each rule.

    Show working

    Rule 1 uses OR: max(0.0, 0.1) = 0.1. Rule 2 uses AND: min(0.2, 0.7) = 0.2. Rule 3 has one antecedent: 0.5.

    Step 3: Aggregation

    Each rule's output set is clipped at its firing strength (low at 0.1, normal at 0.2, high at 0.5), and the clipped sets are combined (union) into one fuzzy set. Scaling is the alternative: the output set is multiplied by the firing strength instead, which keeps its shape.

    Step 4: Defuzzification (centre of gravity)

    Using the sample points from the lecture: membership 0.1 at z = 0, 10, 20; 0.2 at z = 30, 40, 50, 60; 0.5 at z = 70, 80, 90, 100. Calculate the COG (1 decimal place).

    COG = Σ z·μ(z) / Σ μ(z)

    Show working

    Numerator: (0+10+20)×0.1 + (30+40+50+60)×0.2 + (70+80+90+100)×0.5 = 3 + 36 + 170 = 209.
    Denominator: 0.1×3 + 0.2×4 + 0.5×4 = 3.1.
    COG = 209 / 3.1 = 67.4: the project risk is 67.4%.

    6

    Sugeno inference

    Sugeno inference uses the same first two steps, but each rule's consequent is a single number (a singleton), e.g. IF x is A AND y is B THEN z is k.

    Defuzzification becomes a simple weighted average, so Sugeno is faster than Mamdani's centroid calculation.

    Mamdani or Sugeno?

    • Mamdani: intuitive and close to how experts describe knowledge; more computation.
    • Sugeno: computationally efficient; works well with optimisation and adaptive techniques, so it suits control and dynamic nonlinear systems.
    Exercise 6.1

    For the project risk example, the Sugeno constants are k1 = 20 (low), k2 = 50 (normal) and k3 = 80 (high), with the same firing strengths 0.1, 0.2 and 0.5. Calculate the weighted average.

    WA = (0.1×20 + 0.2×50 + 0.5×80) / (0.1 + 0.2 + 0.5)

    Show working

    (2 + 10 + 40) / 0.8 = 52 / 0.8 = 65. Compare with Mamdani's 67.4: close, but not identical.

    Exercise 6.2

    In the simulator at the top, set 30 °C and 75% humidity. Compare the fan speed from Mamdani: clipping, Mamdani: scaling and Sugeno. Which method gives the highest value, and why might they differ?

    Show a model answer

    All three give a high fan speed because the "hot" and "high humidity" rules fire strongly. The values differ slightly because clipping, scaling and Sugeno's weighted average turn the same rule strengths into a single number in different ways: clipping keeps the flat tops of the output sets, scaling keeps their original shapes, and Sugeno uses only one representative value per output.

    Review questions

    Try answering each question yourself first, then open the model answer.

    1. What is an expert system?

    Model answer

    A computer program that captures the knowledge of human experts in a narrow domain, usually as IF–THEN rules, and uses it to solve problems or give advice as an expert would.

    2. What is uncertainty?

    Model answer

    The lack of the exact knowledge that would let us reach a perfectly reliable conclusion. Sources include weak implications, imprecise language, unknown data and differing expert opinions.

    3. What is a fuzzy expert system?

    Model answer

    An expert system that uses fuzzy sets and fuzzy IF–THEN rules, with degrees of membership instead of true/false values, to reason with vague and imprecise information.

    4. What type of problem suits a fuzzy expert system?

    Model answer

    Problems where knowledge is expressed in vague words, inputs change gradually, and an exact mathematical model is hard to build: for example control (fans, washing machines, air conditioning), risk assessment and decision support.
